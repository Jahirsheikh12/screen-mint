# Support

ScreenMint is in beta. Please include enough detail for maintainers to reproduce issues without
guesswork.

## Bugs

Open a GitHub issue and include:

- ScreenMint version.
- Operating system and version.
- Recording source type: display, window, or area.
- Audio settings used.
- Steps to reproduce.
- Whether the issue happens before recording, during recording, in the editor, or during export.
- Screenshots, videos, or logs when safe to share.

Do not attach private recordings or project files publicly. If a file is needed to debug an issue,
share a minimal reproduction that does not contain sensitive content.

## Feature Requests

Open a GitHub feature request with the workflow you want to improve and why it matters. Beta
feedback is most useful when it describes the job you are trying to complete, not only the UI you
expect.

## Security

Use `SECURITY.md` for private vulnerability reports.
