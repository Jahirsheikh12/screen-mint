# Asset Provenance

This file tracks bundled non-code assets for open-source and beta distribution. The
maintainer has attested that the bundled media assets are copyright-free and
redistributable with ScreenMint. Keep this file updated whenever adding, replacing, or
removing bundled media.

## Maintainer Attestation

The ScreenMint maintainer confirms that the bundled wallpapers, audio, cursor artwork,
website media, runtime model files, and WASM/runtime assets listed below are approved for
redistribution in the public beta and open-source repository. New bundled assets must not
be added unless their source, license/status, and proof note are recorded here.

## Release Gate

- Do not delete bundled assets as part of provenance cleanup unless the maintainer explicitly
  asks for removal.
- Public release publishing requires this manifest, `THIRD_PARTY_NOTICES.md`, and
  `LICENSE-UPSTREAM` to list every bundled asset group with a source, license/status, and
  proof note.
- Run `npm run release:validate-provenance` before publishing.
- The unused `public/background-music/*.wav` set was removed in an earlier cleanup so editor
  music has one source directory.
- Keep large assets intentional; consider Git LFS or generated/downloaded packaging if
  repository size becomes a contributor problem.
