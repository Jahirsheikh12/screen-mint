## Before Public Beta

- Replace any asset that lacks clear redistribution rights.
- Remove duplicate or unused media.
- Keep large assets intentional; consider Git LFS or generated/downloaded packaging if repository size
  becomes a contributor problem.
- Update `LICENSE-UPSTREAM` or a third-party notice file with confirmed upstream licenses.
